Cloud UI · Local engine

Install AIPI where your code lives.

Cloudflare hosts the website and dashboard shell. The AIPI Companion runs locally with your MCP server, source code, requests, and logs.

01 · Install

Install the local companion

npm install -g @aipi/companion
aipi status
aipi dashboard

The companion binds to loopback by default. It does not open your project to the public internet.

02 · Connect your IDE

Register the local MCP server

{
  "mcpServers": {
    "aipi": {
      "command": "aipi",
      "args": ["mcp", "start"]
    }
  }
}

Codex or another supported IDE uses MCP over stdio. The agent remains in control of repository changes.

03 · Pair

Pair the cloud dashboard

  1. Sign in at aipi.website.
  2. Choose Connect local companion.
  3. Approve the short-lived pairing code shown by aipi connect.
  4. Choose a project folder locally.

The cloud UI can request approved local operations, but it cannot execute arbitrary shell commands.
